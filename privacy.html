Privacy Policy

Effective October 2, 2026

Rev lets friends use the shared reviewer library without an account. Only the owner can sign in and change that library. Study progress, flags, answers, and prompts remain in each browser.

What Rev stores

Rev stores a shared copy of reviewer questions and exhibits in a private Vercel Blob store, served to visitors through the app. Each browser stores answers, progress, flags, study history, theme preferences, and edited prompts locally. You can export a backup and delete local data in Data & deletion.

Owner sign-in

There is one owner login and no public registration. The owner username and password are configured as private deployment secrets. Sign-in uses a short-lived, HttpOnly session cookie. Visitors do not need to sign in to study.

Hosting and other services

When you use a hosted version, Vercel delivers the site and may process request information needed to operate it. Vercel Blob stores the shared reviewer library; Vercel Functions handle owner sign-in and reviewer updates. Rev does not currently use advertising, analytics, or marketing trackers. PDF reading code and fonts are served with the app. If you import an exhibit by an external image URL, displaying it may contact that image host; attach a local image file to avoid that request.

Retention and deletion

Local information remains in your browser until you remove it, clear browser storage, or delete the browser profile. Backup files you export remain wherever you save them. The owner can change or remove shared reviewers by signing in. Clearing browser data removes only the local copy and study progress, not the shared reviewer library.

Changes

This page describes the current shared reviewer library and owner login. Review the effective date for changes.
