Cookie Policy

Effective October 2, 2026

Rev does not currently set advertising or analytics cookies. It uses browser storage for study progress and display preferences. The owner login uses a necessary HttpOnly session cookie.

Device storage

The shared reviewer library is stored in Vercel Blob. This browser caches reviewers and stores your answers, flags, history, prompts, and preferences in local storage. The owner login uses a necessary, HttpOnly cookie that is not readable by page scripts.

Choices

You can study without signing in. Only the owner can sign in to manage reviewers. You can remove this browser?s study data in Data & deletion or through your browser settings. Owner sign-out removes the owner session cookie. Since Rev does not currently use optional tracking, it does not show a cookie consent banner.

Changes

If optional analytics or advertising storage is added later, Rev will update this page and ask for the consent required before activating it.
